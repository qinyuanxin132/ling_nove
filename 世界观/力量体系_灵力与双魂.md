# 力量体系 · 灵力色与双魂机制

## 四族灵力色
| 族群 | 主色调 | 说明 |
| ---- | ------ | ---- |
| 天族 | 银白 / 淡金 | 秩序、光、正统 |
| 魔族 | 暗红 / 暗紫 | 混沌、力量、暗。暗到发黑的红 = 魔族正统（该当权） |
| 妖族（白狐一脉） | 浅蓝 / 月白 | 水汽、灵动、非天非魔 |
| 人族（道士） | 杂色 / 无色 | 灵力极弱或无色，修行后显现 |

## 人间灵力上限（硬规则）
- 天族：约三成
- 魔族：约四成
- 妖族：约五至六成
- 道士：不受限
- 泠的状态：灵力恢复缓慢（人间受限约五至六成）

## 灵力特性
- 魔族暗红灵力在人间天然不稳定：渗透、腐蚀环境，草木枯、水浊、人病（即使不主动攻击）
- 魔的气息在人间像"暗红色的裂缝"，道士能立刻察觉

## 双魂机制（泠与晞）
- 形态：晞寄居在泠体内"后台"，两魂一体
- 日常：泠在线，晞在后台，可感知但不可干预（除非接管）
- 接管：晞从后台直接接管泠的身体控制权，不是"分身"是"替换"——泠下沉到后台，晞上线
- 接管触发：泠主动让出 / 泠失去意识 / 泠情绪崩溃至极 / 晞判断"必须我来"
- 接管速度：平时约1息；紧急可瞬间接管（晞一直醒着）
- 后台感知：泠被替换后能"看到"晞在做什么，但不干预
- 双魂分身（S+）：泠将晞从体内分离为实体分身，晞可行动、说话、触碰外界。最长三天，持续消耗灵力。**前提：门（裂隙）长好才能使用**——门未修复时晞无法分身为实体
- 印记：晞接管时，右手手背显现暗红色剑形印记（无琰的收纳印记），平时无痕迹

## 门（裂隙）与晞的实力（成长承诺）
- 门=裂隙：同一物的两种叫法。凡人/外人口中的"裂隙"（外观是一道疤），守微人口中的"门"（本质是通道）
- 门未修好（当前状态）：晞只能隔门说话；接管身体受限（天刑后连接管都困难，需慢慢把门撑开）
- 门修好之后：① 晞借泠的身体（接管）时可发挥全部实力；② 晞可作为分身站到人间（双魂分身激活，最长三天，持续消耗灵力）

## 双魂与世界的禁忌
- 天族不知道晞的存在——如果知道，情况会完全不同
- 晞是魔族（暗红灵力），她存在于人间本身就是"魔在人间"——若灵力外泄，道士会察觉魔的气息
- 泠是妖族（九尾），在人间行走已越界，道士见妖拔剑
