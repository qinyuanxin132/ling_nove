# 势力 · 妖族（青丘）

## 定位
山海之间（青丘等），血统、灵智、寿长。人间灵力上限约五至六成。

## 青丘
- 青丘是山，也是国，也是"一种状态"
- 藏在东海之外、云梦泽以南，凡间地图上找不到，只有狐狸能找到回去的路
- 青丘的云是慢的。慢到一朵云从东飘到西，够一只狐狸从幼崽长到成年
- 山上有九条溪流，对应九条尾巴，溪水是温的，四季不冻
- 溪边生"狐火草"，夜里发淡蓝色光，远远看像山在呼吸
- 青丘不排外，但外人进不来

## 青丘的规矩（写在骨血里）
- 九尾为尊，七尾为贵，五尾为常，三尾为末。尾巴越多，离天越近
- 白狐一脉是青丘的执掌者，靠血统不靠武力——白狐的九尾是最接近传说的形状
- 上一只九尾是三百年前的事，死后其尾巴成了青丘的图腾

## 狐族阶位
| 阶位 | 地位 |
| ---- | ---- |
| 九尾 | 为尊（白狐一脉传说级，如泠） |
| 七尾 | 为贵（如泠的母亲，白狐一脉次女） |
| 八尾 | "最接近传说的人"（如泠的父亲，白狐一脉长子） |
| 五尾 | 为常 |
| 三尾 | 为末 |

## 九尾特征
- **衣袋装不满**（空间袋）：九尾白狐的衣袋是空的兜——怎么装都不见鼓，装多少都装得下。九尾特征，青丘人尽皆知（第50章：泠的母亲知道，"九尾的衣袋，装不满"）
- 容量边界、是否独属九尾、能否装活物——待写

## 与各方关系
- 与天：不干涉，不信赖。妖在青丘待着，天不动；妖在人间作乱，天出手
- 与魔：不结盟，不竞争。没有利益冲突，但绝对不结盟
- 与人：可以共存，可以成友。人帮妖隐匿行踪、提供食物；妖帮人看病、指路
- 与道士：嫉恶如仇。道士见妖拔剑，不区分好妖坏妖

## 妖族眼中的天
- 天不惹事：不入侵青丘，不插手妖族内部事务
- 天不帮忙：妖族没有向天求援的传统
- 天太远了："它在上面，我在这里。不相关。"

## 例外案例：泠
- 青丘九尾，离开青丘，在人间行走，没有作乱
- 天族可能知道她，但没有派人追——因为：她没有犯事，只是路过
- 她体内还有一个天族不知道的存在（晞）。如果天族知道，情况可能会不同
