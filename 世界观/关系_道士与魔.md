# 世界观 · 道士与魔（关系细则）

## 基本关系
绝对敌对。道士见魔，比见妖更决绝。妖还有"可能不犯事"的空间，魔在道士眼中不存在"可能"——魔出现，就是威胁。

## 道士对魔的立场
魔是人间最大的威胁。妖会作乱，但妖有地盘、有规矩、有"不犯事"的可能。魔没有这些。魔界本身就不守规矩，魔在人间行走，不可能是来"路过"的。

## 魔对道士的立场
道士是"人间长出来的石头"。挡路、麻烦、打不完。魔族不恨道士，但嫌他们碍事。遇到道士，魔族不会绕路——他们会直接打，打完再走。

## 魔一定会害人（两条原因）
1. 魔的灵力特性：暗红灵力在人间天然不稳定。魔族在人间行走时，即使不主动攻击，其灵力也会渗透、腐蚀周围的环境。草木会枯，水会变浊，靠近的人会做噩梦、生病、逐渐虚弱。魔不是"故意"害人，但魔的存在本身就是对人间环境的破坏
2. 魔的行事逻辑：魔族不理解"不伤害"这个概念。强者为尊，弱者不该存在。遇到挡路的就移开，遇到不顺眼的就打倒，遇到饿了的就吃。魔界生存法则里没有"怜悯"的位置

## 道士与魔的冲突
| 情况 | 道士的应对 |
| ---- | ---------- |
| 魔族出现在人间 | 立刻知道（魔的气息像暗红色的裂缝），直接赶往那个方向 |
| 魔族主动攻击道士 | 打，不留手 |
| 魔族主动伤害人族 | 打，不留手 |
| 魔族试图在人间建立据点 | 联合周边道观共同清除，并上报天庭 |
| 魔族只是路过 | 依然追。因为"路过"这件事本身在人间就不被允许 |

## 为何不会和解
1. 人间的脆弱性：人间承受不起"万一"。魔族只要在人间停留过，就会留下痕迹。痕迹会吸引更多魔族。道士不可能等"看看这个魔会不会害人"再动手
2. 魔族的不可理解性：魔族不理解"无害"这个概念。道士也理解不了"为什么魔族要跑来人间"
3. 天族的立场：天族认同道士的立场。在人间发现魔族，天族和道士站在同一边。双方在"魔不该在人间"这件事上是一致的
