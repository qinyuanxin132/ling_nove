# 势力 · 道士

## 定位
人间的防线，守护与被守护。

## 道士的立场
- 修的道以"护人间、斩妖邪"为根基
- 道士见妖，嫉恶如仇。不是"分情况讨论"，是看到了就要拔剑。妖在人间行走本身就是越界
- 道士见魔，比见妖更决绝。魔在道士眼中不存在"可能"——魔出现，就是威胁
- 道士不依赖天族：修的道是以人间自身的力量对抗妖魔，天族的帮助是"额外的"，不是"必须的"

## 行动规则
| 情况 | 道士的行动 |
| ---- | ---------- |
| 魔族出现在人间 | 立刻知道（魔的气息像暗红色的裂缝），直接赶往那个方向 |
| 魔族主动攻击道士 | 打，不留手 |
| 魔族主动伤害人族 | 打，不留手 |
| 魔族试图在人间建立据点 | 联合周边道观共同清除，并上报天庭 |
| 魔族只是路过 | 依然追。因为"路过"在人间不被允许 |
| 妖与人成为朋友 | 不主动拆散，但会记录 |
| 道士发现妖人友谊 | 警告妖离开，警告人"你正在做不该做的事" |
| 人坚持与妖在一起 | 不抓人，但列入观察名单 |
| 妖在人与道士之间选择留下 | 动手 |
| 人和妖一起逃走 | 追 |

## 道士为何不承认"好妖"
- 妖可以伪装成好的：十年、五十年、一百年，然后在某个瞬间因为一个念头的偏差变坏
- 道士守护的人间承受不起那一瞬间
- 很多道士年轻时也遇到过"看起来很好的妖"，也在某次意外后从此不再相信"好妖"
- 承认妖与人的友谊正当 → 更多妖认为"人间可以待" → 更多人结交妖 → 某天一只出问题，道士要负责收场
- 人间的规则不能被例外打开

## 道士为何不与魔族和解
- 人间承受不起"万一"：魔族只要停留过就留下痕迹，痕迹吸引更多魔族
- 魔族不理解"无害"这个概念
- 天族认同道士的立场，双方在"魔不该在人间"上一致

## 与天族协作
- 关系：目标一致，不隶属。不崇拜天族，但承认天族的存在
- 日常：道士自己处理妖魔事务，不喊天
- 紧急：向天求援，天族回应
- 事后：天族回天上，道士继续守人间，两边不再见面
- 天族偶尔通过某些道观传递信息，道士接到后执行——不是"服从"，是"这件事本来就该做"

## 边界
- 道士守护人间边界
- 天族巡逻天界边界，两边各自管自己的线，偶尔重叠
