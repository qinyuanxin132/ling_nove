# 势力 · 天族

## 定位
九天之上，秩序、律法、审判。人间灵力上限约三成。

## 天族的分级（职司体系）

天族的"等级"不是灵力境界，而是职司与权限。修为依年岁与功绩渐长，职衔不严格等于战力——老巡天卫可能强过新执星官；但权限（调阵列、施律法、开战务）只随职衔走。

### 等级总表

| 等级 | 职衔 | 职司 | 人间灵力 |
| ---- | ---- | ---- | -------- |
| 一 | 巡天卫 | 边界巡逻、封锁、缉拿编队的基础单位 | 三成封顶 |
| 二 | 执星官 | 带队军官，领十至数十巡天卫 | 三成封顶 |
| 三 | 天将 | 战斗序列高位，清理人间作乱、领整编出战 | 三成封顶 |
| 四 | 九天长老 | 议事决策层，断大事、议天刑、处置越界者 | 三成封顶（天刑除外） |
| 五 | 天君 | 天界之主，不直接出手，决策经长老院 | —（不现身人间） |

### 各等级详解

**巡天卫（一等）**
- 天族最底层正式编制，白袍。专职边界巡逻与封锁，负责"看见"——天界边界按分野分段驻防，人间边界是观察线，巡天卫偶尔巡到（第33章）
- 单兵战力有限，强在阵列：多人合击织"灵力网"，网越织越密，成形后脱身极难。缉拿编队的标准做法是结网围困，而非强攻
- 单人的网可以被破——晞当年贯穿右侧巡天卫肩甲、只走直线杀出重围（第30章回忆）

**执星官（二等）**
- 带队军官，一人领十至数十巡天卫。"执星"取自"执星巡边"：看星辰分野、察各境气数异动
- 可单独执行中低烈度任务：查报、驱赶、缉拿。晞越界被围那次，正是"执星官一人+巡天卫十一人，阵列整齐，灵力交织成网"——缉拿的标配规格
- 执星官级别出手=天界认为"有人越界"；不认为是"大患"
- 众执星官以二十八宿分野编制，各管一段辖区；星官之首为太阴星君——掌月的那位（详见 神职要员·嫦娥）

**天将（三等）**
- 战斗序列高位，天庭派遣清理人间作乱妖族、大规模魔患的正式战职（关系·天与妖：作乱则"天庭派遣天将清理"）
- 可独行，可领整编巡天卫（数百人）出战。有专属兵器法宝。天将出动=事态升级，不是巡查能收场的了

**九天长老（四等）**
- 议事决策层，白发、长袍、眉目如雪。不行常事，只断大事：裁定魔患规格、议定天刑、处置天族级别的人物
- 可代天行罚——天刑即长老亲施（第20章）
- 下凡极少。长老下凡=天界已把此事定为"必须了断"的规格。十七年前晞越界一战，天族出动的是长老而非天将——这是给魔族公主的规格，也是给"正统血脉"的规格
- 与魔族四王处于对峙层次（两族顶级都不轻动）

**天君（五等）**
- 天界之主。不直接出手，决策经长老院。**书中暂不正面出场——第70章起突破：不现身于公开场合（内侍"天君不见客"照旧），但私下会到王母殿与王母议事（"他不常来"）；他对王母说的话里藏着自己的分寸（70章"我就是知道"）**
- 天族与魔族的最高层结构差异即在此：魔族四王并列、强者为尊、无共主；天族有共主、律法单一。两族谁更"像"一个政权，一目了然——但也正是魔族的多王割据，让天族始终算不净魔界
- 破例旧案（未来规划）：长老之女女娲曾为救一个被定天谴的九尾（泠）跪求天君。天君始终未现身，云端传声允了，但条件有二：一、泠由女娲家看管，不得离开半步，人间事了后送归；二、对泠的力量施以封印——封印锁的是灵力上限，足以支撑泠日常战斗，以泠目前的境界远触不到限制。**真正的原因（核心设定）：他认出了她。**天君之强——不是气息外漏，是他隔着云端一眼看穿十七年藏匿：门里那道暗红，是晞。女娲的跪求只是台阶，他需要一个"合规矩"的理由来破例。封印的另一层用意：压住晞在天界能动的上限——她若在天界放分身、接管战斗，暗红瞳色与暗红灵力就是行走的通缉令。他封的不是"她会被查到"，是"她别自己暴露"。他始终未现身——是不敢见她，还是怕被她认出，写作时不要挑明
- 幼年旧事（少帝时期，背景设定）：他还不是天君时，遇见过一个越界的魔族女孩——晞。少帝没有喊人，带她玩了几天（爬云、看星星、摘果子），两人逐渐生出好感；被长老撞破后强行拆散，长老要处置那女孩，他哭着求饶，才换她平安回到魔族。此后他再没哭过——这是长老院心照不宣的旧话。如今的天君不现身、云端传声、疏离如雪，是少年那件事之后长成的样子（留白，不写死）
- 十七年（坠凡之后）：天界查她，他从不亲自过问——他以为她坠下去时就已经没了（那一战最后一击是天族给的，F-005 悬置）。十七年里，他从没想过她还活着。直到长老家的女孩把一只九尾带上天，他隔着云端看了一眼——门里那道暗红色动了动，像十七年前，她站在边界线上回头看他时的样子（写作可用意象，别挑明）
- 两次破例之间的呼应（写作可用）：女娲跪求那次，是他此生第二次为魔族侧的人破例——第一次，他哭得求了饶，没留住人；这一次，他连面都没露，却答应了（因为他认出了她）

## 神职要员（特殊存在）

**女娲 —— 九天长老之女（天族女孩，无职司）**
- 九长老之一（其父）的女儿，比泠小3岁（泠17岁时她14）。民间传说里"女娲造人、补天"的神话是后人借她的名字编的——本作世界里没有太初女娲，她只是个天族小女孩
- 外貌：天族正统血脉——银白长发、淡金色眼睛，比泠矮半头。血脉正统，灵力潜力高，但现为幼年，灵力尚浅
- 未来关键剧情（规划）：
  1. 其父在人间巡查时**拿捕**重伤的九尾少女（泠，被强大的道士长老围攻受伤，银项链掩住魔气但掩不住形貌）——**涉魔之妖按天律当诛**（敌意，用户定案）：带回天界、暂留看管（38-39章已实现）；女娲发现并成为玩伴；**但泠注定要被带走**（长老院过问、天律当诛）——女娲向天君跪求，天君看穿泠和晞后帮助救下（详见 天君条目）；**为不引人注目，给泠"女娲贴身侍卫"的职位**（贴身保护女娲，掩人耳目，用户定案）
  2. 没几天，女娲与泠成为玩伴
  3. 泠被救下后某一天，主动把晞的事告诉了女娲——女娲是天族里唯一知道晞的人
  4. 长老院复查察觉泠身上有蹊跷（银项链+长好的门挡住常规查探，长老们只觉"这九尾不寻常"，查不出所以然），天谴在即——女娲向天君跪求
  5. 天君破例允了（真正原因：他认出了门里的晞——详见 天君条目；女娲的跪求是给他的台阶，也是给他的理由），泠留下来，与女娲一起成长；女娲家人待泠不错
- 写作约束：天族女孩的视角里没有"妖该除"的成见，她看泠就是看一个姐姐；胆子大，敢为在乎的人跪下去

**王母娘娘（西王母）—— 九天长老之首，实际掌权者**
- 天君是象征（不现身、不管事）；长老院九位长老管具体大事；王母是九长老之首，代天君理政。实权在王母手里
- 掌两样东西：
  - **不死药**：天族最高赏罚之物——赏有功者，罚者连闻都闻不到
  - **蟠桃会**：天族议事的场合（不是寿宴，是朝会）。蟠桃按位份分等，位份越高果子越老——吃不吃是情分，排不排上桌是身份
- 第20章下凡施天刑的那位长老，是她座下的九长老之一。长老下凡的规格，实为她的意思
- **第70章进展**：天君私访提议把静默台的狐狸放出来端茶倒水，她当面拒绝（"那是刑犯。不是宠物"）；独坐后转变——送信考验通过（"送到了"三个字、那三天不跑）+ 静默台是她布的阵、她看见过九尾裹着女娲（"她活了几万年。没有人敢这样蹭过来。没有人把日子数给她"）→**亲至静默台收泠做殿前宠物**（取消监禁；端茶倒水；百年起步、坐满百年还自由身；刑期一笔勾销；"别的，不用你做。我让你做什么，你做什么"）；入殿第一杯茶"手稳"；"你飞的那三天，我看过了……你没跑"（69章"天上看着呢"兑现）——**她收泠不全为试探，有真心要一个"近身的人"的意思（留白）**

**嫦娥 —— 太阴星君（执星官之首，有名无实）**
- 众执星官以二十八宿分野巡边，太阴星君是星官之首，掌月——月相、潮汐、夜里妖物们凭依的光
- 旧案：她曾是王母面前得宠的星君，后来**盗食不死药奔月**，被贬守月宫。如今官职还挂着，人只在月宫守着，不理天族政事
- 月宫冷清，无人敢提她——"嫦娥"三个字在天族是避讳。她是天族里另一个"被关起来的存在"（如晞在门里、泠被禁足青丘）
- 顺带可埋的钩子：她这桩旧案是全天下唯一能引出"不死药"的线索——若有人再问起不死药，就会问起嫦娥，旧案是可以翻的
- **第69章进展**：王母让泠送信至月宫（试探泠）——嫦娥收信（"……我知道了。替我谢娘娘"），看穿泠飞了三天（"你飞来的""飞了三天"），点破"她这是拿你当秤试呢"；**与泠初识："你叫什么？""泠""泠。……我记着了"**；月宫桂树下玉兔仍在捣药（不死药余韵，F-076）；王母与嫦娥私下有通信往来（信的内容未揭，F-075）

## 战力参照（写作基准）
- 晞（未重伤、全力）：单破"执星官+十一巡天卫"结网阵列，不缠斗只走直线——灵力规格在天将之上、接近长老级。正统血脉的含金量
- 巡天卫单兵 ≈ 中层妖将水准；结成灵网后可围高于自身数级的对手
- 天刑：律法级刑罚，由长老代天行罚，**不受人间三成限制**（第20章封魔百日）；需长老院议定，不能私施；天将及以下无权
- 人间三成上限对天族全员封顶，与等级无关——是人间本身压着所有外来者

## 行为逻辑
- 天存在的意义之一就是压制魔
- 天族认为魔界是"裂缝"、"错误"、"本该愈合但没能愈合的空洞"，不承认魔界是合法的地方
- 天族不主动干预人间日常，但遇到"明显需要干预"的情况会出现

## 行动规则
| 情况 | 天族的行动 |
| ---- | ---------- |
| 妖魔在人间作乱 | 派人查看，确认危害过大则出手 |
| 弱势的人被妖魔所害 | 会出手，不会让人间出现"大规模被压着打"的局面 |
| 道士求救 | 大多数不回应；事情确实严重才出动 |
| 普通人间事务 | 不干预（战争、饥荒、疾病是人间自己的事） |
| 魔族越界到人间 | 警告驱逐或直接清理 |
| 魔族入侵人间 | 立刻出手 |
| 魔族试图扩张边界 | 直接打，无警告无谈判 |
| 妖族在人间作乱 | 天庭派遣天将清理 |
| 妖族大量进入人间 | 查看原因；内部乱子不插手，入侵意图则直接介入 |

## 天族逻辑
人间应该自己站稳。但如果人间站不住了，天会扶一下。

## 与各方关系
- 与魔：绝对对立（详见 势力·魔族 与 天与魔关系）
- 与妖：不干涉，不信赖
- 与人：不干预，会帮扶弱势
- 与道士：目标一致，不隶属

## 边界
- 天族巡逻天界边界
- 天↔魔之间有默认边界线，没有墙没有标记，双方都清楚
- 天族越界到魔界，魔族也会打
