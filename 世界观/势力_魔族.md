# 势力 · 魔族

## 定位
九幽夹层（天与地之间的夹层），混沌、力量、乱。人间灵力上限约四成。

## 行为逻辑
- 强者为尊，乱者为王
- 魔族不理解"不伤害"这个概念。遇到挡路的就移开，遇到不顺眼的就打倒，遇到饿了的就吃
- 魔族不主动怜悯——魔界的生存法则里没有"怜悯"的位置
- 魔族认为天是"想要抹掉我们的人"，自己不是错误，天才是"管得太宽的人"

## 行动规则
| 情况 | 魔族的行动 |
| ---- | ---------- |
| 魔族出现在人间 | 必然造成损害：草木枯、水浊、人病（暗红灵力天然不稳定，渗透腐蚀环境） |
| 遇到道士 | 不绕路，直接打，打完再走 |
| 天族越界到魔界 | 也会打，不让天族进入夹层 |
| 天族在人间长期驻留 | 认为"天在扩张"，可能在边界施加压力 |
| 天族削弱魔族势力 | 用对等方式回应 |

## 魔界地理
- 天空暗红色（血稀释后映在天上的颜色）
- 河流不往低处流，绕着山走、绕着城走，像流水有自己的脾气
- 山不长草，长黑色矮灌木，夜里发出极细的、像呼吸一样的声音
- 整个魔界都在呼吸——很慢，很沉，不太在意你的存在

## 与各方关系
- 与天：绝对对立（不开全面战：夹层会崩，人间会遭殃）
- 与妖：不结盟，不竞争（"魔是魔，妖是妖"）
- 与人：必然害人（不一定是主动作恶，但存在即破坏）
- 与道士：绝对敌对（道士见魔直接拔剑）

## 魔族内部
- 魔界四王之一：晞的父亲，镇守东境，以"不动"闻名。魔性不是暴烈的那种，是沉的那种
- 晞：魔族公主，血脉纯正，灵力色暗红暗到发黑（正统，意味着该当权），但"空有血脉，没有魔性"，从不参与族中争夺
- 内乱：魔族内部会爆发内乱（晞的妹妹死于一场内乱）

## 边界
- 魔族与天族之间有默认边界线，越线意味着开战
- 魔族在魔界内部活动，天族不干预但监视边界动向
