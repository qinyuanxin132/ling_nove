# 力量体系 · 裂隙（晞与泠的连接机制）

来源：D:\ling_xi\世界观\裂隙.txt（2026-08-08 更新）

## 它是什么
裂隙不是伤口。不是封印。不是寄生。

它是晞坠落时撞进泠体内留下的那道"入口"——她进来的时候太急、太重，没有找到合适的落脚点，于是在泠的灵力通路和身体边界之间撞出了一道裂口。那道裂口没有愈合，不是因为泠的身体不行，是因为晞进来之后，她的存在本身在持续撑开那道入口的宽度。它不是"晞"，但它是晞存在的方式。

## 它的形状
- 外观：一条极细的缝（从肩胛骨到腰侧的纵向细线），常人看去像一道旧疤，**脱衣服才能看到**；从内部感知，它是纵向贯穿泠左侧躯体的一条裂隙
- 宽度不定——安静时就是一条缝（像疤），情绪波动时变宽，完全张开时像一道裂谷
- 边缘是温的，有时会渗光（晞说话时缝缘泛暗红）

| 状态 | 裂隙表现 |
| ---- | -------- |
| 平静时 | 一条细缝，常人看像一道旧疤（脱衣才可见），几乎感知不到 |
| 晞说话时 | 缝缘微微发亮，泛暗红色 |
| 情绪波动时 | 变宽、发热、泠的左手会轻微发麻 |
| 战斗时 | 完全张开，暗红灵力从裂隙中涌出 |
| 天刑击中时 | 裂隙剧烈收缩，像一扇被强行压住的门 |

## 它连接什么
裂隙连接的不是两个空间，是两个存在。泠在裂隙的这一侧，晞在裂隙的那一侧。晞不能随意穿过它，但她的感知、声音、灵力都能通过裂隙渗透到泠这一侧。泠也不能随意关闭它，但她可以让它变窄。

## 它的本质
它是一道"不完全的门"。它不是被设计出来的，是被撞出来的。晞摔进来的时候，她没有钥匙，泠也没有锁。那道裂隙就是她们之间唯一的存在方式。

## 裂隙与门：同一个东西，两种叫法
**裂隙 = 门。** 它们是同一件事物的一体两面，不是两个东西：

| 叫法 | 指什么 | 场景 |
| ---- | ------ | ---- |
| 裂隙 | 它在泠背上的**外在形态**：从左肩胛到腰侧的一道细缝，常人看像旧疤（脱衣才见），晞说话时缝缘泛暗红 | 平时描述、旁人视角 |
| 门 | 它的**本质**：一道连接两个存在的通道（不完全的门）。"门里"=通道内部=晞的居所（她来的地方，天是暗红色的） | 守微人视角、守微录所见、重要时刻 |
| 门里 | 通道内部、晞住的地方。晞透过门说话、感知、偶尔接管泠的身体出来透气 | 晞说话时（"门我守着"） |

**关键规则（防止再乱）：**
1. **门长在泠背上，是泠身体的一部分**（灵力通路与身体边界之间的裂口）——泠去哪，门去哪，晞去哪。晞不是"跟着"泠走路，她住在门里，天然随泠同行。
2. **晞不能离开门**：她出不来，只能透过门说话；想真正出来透气，要靠泠让出身体（接管，第18章）；天刑钉门时她连声音都断断续续。
3. **门可以被攻击**：天刑打中门→门被钉死（封魔百日）；石室压制→门显形加深、被压坏；失控=门被撑开，暗红灵力涌出。
4. **门现在的状态**：被天刑打坏过（变形），正按守微录的真法"慢慢长"（门不是修的，是长的，路长好了门就顺了）——长在泠背上，晞在门里看着它长。
5. **"门我守着"的正确读法**：晞盯着门的状态、看着它长——不是留下不走（她没法留下，门跟着泠走）。

## 与双魂机制的关联
- 平时：晞通过裂隙感知、说话（裂隙泛暗红）
- 接管：晞完全通过裂隙进入泠这一侧（战斗时裂隙完全张开，暗红灵力涌出）
- 潜在风险：裂隙是泠身体上的裂口——若被外力击中（如天刑），裂隙剧烈收缩；江岫可在三息内封住裂隙，但封存过程中裂隙里的存在（晞）会受伤
