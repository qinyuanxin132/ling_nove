# 世界观总览

## 世界核心设定

### 四族定位
| 族群 | 居所 | 核心特征 | 人间灵力上限 |
| ---- | ---- | -------- | ------------ |
| 天族 | 九天之上 | 秩序、律法、审判 | 约三成 |
| 魔族 | 九幽夹层 | 混沌、力量、乱 | 约四成 |
| 妖族 | 山海之间（青丘等） | 血统、灵智、寿长 | 约五至六成 |
| 人族 | 人间大地 | 寿短、灵弱、数量多 | 不受限（道士） |

### 四族立场汇总
| 族群 | 对天 | 对魔 | 对妖 | 对人 | 对道士 |
| ---- | ---- | ---- | ---- | ---- | ------ |
| 天 | — | 绝对对立 | 不干涉，不信赖 | 不干预，会帮扶 | 目标一致，不隶属 |
| 魔 | 绝对对立 | — | 不结盟，不竞争 | 必然害人 | 绝对敌对 |
| 妖 | 不干涉，不信赖 | 不结盟，不竞争 | — | 可以共存，可以成友 | 嫉恶如仇 |
| 人 | 不干预，会帮扶 | 必然害人 | 可以共存，可以成友 | — | 守护与被守护 |
| 道士 | 目标一致，不隶属 | 绝对敌对 | 嫉恶如仇 | 守护与被守护 | — |

### 四族灵力色
| 族群 | 主色调 | 说明 |
| ---- | ------ | ---- |
| 天族 | 银白 / 淡金 | 秩序、光、正统 |
| 魔族 | 暗红 / 暗紫 | 混沌、力量、暗 |
| 妖族（白狐一脉） | 浅蓝 / 月白 | 水汽、灵动、非天非魔 |
| 人族（道士） | 杂色 / 无色 | 灵力极弱或无色，修行后显现 |
