# 全书大纲

## 主线脉络
- **青丘篇**（第1-6章）：九尾降世于青丘（父母"她会很难"），内住魔族少女晞（门/裂隙）；遭排挤，十七岁离丘寻自由
- **人间篇**（第7-24章）：入人间为狐、江岫收留（守微人）；与晞磨合；西行治门；天刑钉门、禁足百日；父亲赠银狐狸项链；再回人间，守微录认主
- **长路篇**（第25-34章）：江岫同行沿新线西行（守微录指路）；门长好、晞分身凝成；寻师线与边界线双线；旧门入魔界（第七卷开）
- **魔界篇**（第35-37章）：摘甜梨、东境父亲未相认、妹妹坟前放梨；魔界在找"王族的血"（非追杀，是寻+敬）
- **天界篇**（第38-47章）：回人间漏耳尾被道士围攻、被九天长老拿捕入天界（涉魔当诛）；女娲求情→暂留；长老院查验定案→女娲跪求天君→天君看穿门、当众赦免；侍卫职位；泠告知晞；魔界起兵风声
- **战争与成长篇**（第48-55章）：魔界攻天、九天长老战死（碑朝人间）；青丘暂住、青鸟传信、归途（难民/救助）；葬礼（泠挽魂）、天君夜召（十七年旧事揭晓，"……认得。"）；三年成长、女娲接父位；共工触不周山、女娲炼五色石补天；泠杀黑龙济冀州
- **朝歌篇**（第56-63章，规划）：女娲与泠同游朝歌，见神像被亵渎；女娲沉默返天界；泠独自留朝歌——不杀人不放火，只让纣王怀疑截教大臣（谣言/伪信/魅惑）；商朝内部撕裂，牧野之战败、朝歌城破；鹿台对峙"我只是让你看见了你不愿看见的东西"，纣王自焚
