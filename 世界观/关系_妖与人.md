# 世界观 · 妖与人（关系细则）

## 基本关系
可以共存，可以成为朋友，但不会得到道士的承认。

## 人对妖的态度
普通人对妖没有统一的看法。有人怕，有人好奇，有人愿意接近。妖不主动害人的话，人不会自发地讨厌妖。

## 妖对人的态度
妖不排斥人。妖看人像看另一种存在——活的、短的、有趣的东西。好妖不会主动伤害人，坏妖会。但大多数妖对人无感。

## 妖与人的友谊（真实存在）
妖有情感，人有情感，双方在长时间的相处中可能建立信任。
- 妖帮人：看病、指路、驱赶野兽
- 人帮妖：隐匿行踪、提供食物、在道士面前替妖说话

这样的友谊是可能的。但不是因为道士允许了，是因为道士没看到。一旦道士看到了——友谊的双方都会付出代价。

## 道士不会承认的原因
1. 道士的职责是守护人间，而妖在人间本身就是被允许之外的例外。承认"妖与人之间的友好关系"是正当的，就等于承认"妖可以在人间自由行走"
2. 道士见过太多例子：年轻时也遇到过"看起来很好的妖"，也在犹豫后，在某次意外中看到妖失控、被逼到绝路、或没忍住饥饿。道士从此不再相信"好妖"这个说法——好妖只是还没到临界点的妖
3. 承认的后果：更多妖认为"人间可以待"，更多人尝试结交妖，更多妖因为人类的信任留在人间——某天其中一只出了问题，道士要负责收场

所以道士不承认。不是因为他们恨人，也不是因为他们恨妖。是因为他们知道——人间的规则不能被例外打开。

## 实际中发生了什么
| 情况 | 道士的应对 |
| ---- | ---------- |
| 妖与人成为朋友 | 不主动拆散，但会记录 |
| 道士发现了这段关系 | 警告妖离开，也警告人"你正在做不该做的事" |
| 人坚持与妖在一起 | 不抓人，但把此人列入观察名单 |
| 妖在人与道士之间选择留下 | 动手 |
| 人和妖一起逃走 | 追 |
