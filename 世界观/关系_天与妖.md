# 世界观 · 天与妖（关系细则）

## 基本关系
不干涉，不信赖。天族不主动管妖族的事，但也不信任妖族。

## 天对妖的立场
- 妖不是魔：妖族不天生与天对立，有自己的地盘（青丘等），不乱跑，不乱动。天族不会把妖族列为"必须清除"的对象
- 妖也不值得信任：妖的血统不稳定。九尾可以变成好妖，三尾也可以变成坏妖。天族只认一条原则：妖在人间作乱，天要管；妖在青丘待着，天不动
- 妖在天之下：不是蔑称，是位置。妖可以抬头看见天，但天不会低头回应妖

## 妖对天的立场
- 天不惹事：不入侵青丘，不插手妖族内部事务，不对妖族的血统指手画脚
- 天也不帮忙：妖族没有向天求援的传统。遇到冲突，妖靠自己
- 天太远了："它在上面，我在这里。不相关。"

## 边界
| 情况 | 天族的行动 |
| ---- | ---------- |
| 妖族在青丘境内活动 | 不干预 |
| 妖族在人间行走（未作乱） | 观察。但不会主动出手 |
| 妖族在人间作乱 | 出手。天庭会派遣天将清理 |
| 妖族与魔族产生冲突 | 不站队。不会帮妖族打魔族，也不会帮魔族打妖族 |
| 妖族大量进入人间 | 查看原因。内部乱子不插手；有入侵人间的意图则直接介入 |

## 例外：泠的情况
对天族来说属于"边缘案例"——她是青丘九尾，但离开了青丘。她在人间行走，没有作乱。天族可能知道她，但没派人追她，因为：
1. 她没有犯事
2. 她只是路过
3. 她体内还有一个天族不知道的存在（晞）

如果天族知道晞在她体内，情况可能会不同。但目前——天族没有理由动她。
