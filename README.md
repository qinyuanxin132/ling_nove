## 📖 关于这本书

九尾白狐泠，青丘唯一九尾，因“太好”而被排挤，走出青丘。魔族公主晞，因“太善”而不被魔族接纳，越界后被天族围捕，重伤坠落至泠体内。

两个被各自族群抛弃的人，共用同一个身体，在人间行走。

这个世界没有她们的位置。但她们有彼此。
