# 世界规则

（本文件记录世界观中必须强制生效的边界规则，写作时不得违反）

## 生效边界规则

| 规则 | 说明 |
| ---- | ---- |
| 人间边界 | 妖、魔、天在人间灵力都受限。天族约三成，魔族约四成，妖族约五到六成。道士不受限 |
| 天刑例外 | 天刑为律法级刑罚，由九天长老代天行罚，不受人间三成限制；需长老院议定，天将及以下无权 |
| 越界定义 | 魔族越界到人间 → 视为挑衅。天族会出手，道士会拔剑。妖族越界到人间 → 看是否作乱。作乱则收，不作乱则观察 |
| 边界管理 | 天族巡逻天界边界，道士守护人间边界。两边各自管自己的线，偶尔重叠 |

## 种族铁律（防OOC硬性规则）

- 道士见妖拔剑：不区分好妖坏妖，因为"好妖"只是还没出事的妖
- 道士见魔直接拔剑：魔出现在人间就是威胁，不存在"路过"的可能
- 魔在人间必然害人：不是主动作恶——魔的暗红灵力在人间天然不稳定，草木枯、水浊、人病
- 天↔魔不开全面战：夹层会崩，人间会遭殃，两边都打不起
- 妖↔魔不结盟：两边都不信任对方，没有共同历史就没有信任基础
- 道士与妖友情的代价：道士不承认妖与人的友谊，一旦发现会记录、警告、追踪
